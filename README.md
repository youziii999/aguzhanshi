# 重生之我是股神 · A 股模拟交易

一个**零依赖、零构建、双击即玩**的 A 股模拟交易游戏。K 线不是随机数画出来的，
而是由每一笔"成交"对盘口的冲击一点点推出来的：小单推不动，大单能推，新闻改变深度。

打开方式：直接双击 `stock-game/index.html`（file:// 即可运行，不需要服务器、不需要联网）。

## 一、玩法

三个页面，手机上底部切换（同花顺式）：

| 页面 | 内容 |

| 行情 | 上证指数 + 涨跌家数 + 两融资金四档 + 涨跌分布 7 档 + 16 个板块 + 今日榜单（涨幅/跌幅/成交额/涨停板/龙虎榜）+ 224 只个股列表（可排序） |
| 个股 | 报价 + 市值/换手/量比/振幅/涨速/市盈率 + 分时与 9 种周期 K 线 + 五档盘口 + 四类资金净流入 + 下单 + 持仓/委托/成交三页签 + 消息 |
| 我的 | 总资产 / 盈亏 / 净值曲线 / 可用·冻结·市值·成本 / 持仓 / 成交 / 重置 |

**操作**

| 操作 | 位置 |
| --- | --- |
| 选板块 / 选股 | 行情页点板块按钮筛选，点任意一行进个股页 |
| 下单 | 个股页交易面板：填价 = 限价委托，不填价 = 市价委托；1/4 1/2 3/4 全部 快速定量 |
| 管单子 | 个股页持仓面板三个页签：持仓（带 T+1 标记）/ 委托（可撤单）/ 成交 |
| 加速 | 顶栏 暂停 / 1× / 2× / 4×，1× 时 1 分钟 = 1.5 秒，一天 6 分钟 |
| 重开一局 | 顶栏 ↻ 或「我的」页底部「重置」（点两次确认，换一套全新行情，可重选资金） |

**交易规则（A 股口径）**

- T+1：当天买入的股票 `avail` 为 0，次日开盘才解禁
- 涨跌停：主板 ±10%，创业板/科创板 ±20%；委托价越界直接拒单
- 费用：佣金万 2.5（最低 5 元）+ 卖出印花税 0.05% + 过户费万 0.1
- 委托当日有效：收盘未成交的委托自动作废；未成交的买单资金一直"冻结"不可用
- 启动资金 1 万 ~ 20 万可选（滑块 / 5·10·15 万快捷档 / 手动输入），首次进入和重置时都会问
- 存档在 localStorage（`sg-save-v1`），从点「开始交易」那一刻才开始存，刷新自动续上

## 二、价格是怎么被单子推上去的

核心在 `js/engine.js` 的 `hit()`——**全引擎唯一改写价格的地方**，模拟单和玩家单都走它。

**1. 盘口深度决定"一笔单能推多少"**

```
一档挂单额 firstLevelValue = 日均成交额 / 240 × DEPTH(0.96) × 流动性系数 liq
```

所以茅台一档六十多万、万科一档几千块——同样 100 万的单，在万科身上能把价格顶好几个点，
在茅台身上连一格都推不动。

**2. Kyle lambda 冲击**

```
dr = clamp(成交额 / 一档挂单额 × IMPACT, -3%, +3%)     IMPACT = 3.36e-4
press += 方向 × dr                                       press 按 0.97/微步 衰减
攒够一个最小变动价位 tick 才走一格：pc += mv × tick
```

价格用**整数"分"**存储，永远不会出现浮点漂移。tick 自适应 = 股价 × 0.005%（不低于 1 分），
否则 6 元的工行和 1743 元的茅台没法用同一套深度参数做出同一个波动率。

有个反直觉的结论：`dr / tick = 41.7 × IMPACT / DEPTH`，**和股价完全无关**。
这就是为什么改 DEPTH 曾经"毫无效果"——它只通过这个比值起作用。

**3. 每分钟怎么"下"这些单**

一天 240 分钟 × 4 个微步。每分钟：

```
成交额预算 = 日均成交额 / 240 × U 型活跃度 × 噪声      （U 型 = 开盘收盘活跃、午间清淡）
笔数       = ordRate / 4（clamp 到 2 ~ min(60, 手数上限)）
每笔手数   = 预算换算的总手数 × 该类别倍率 × 对数正态抖动
```

先算总手数再分配，是为了绕开"1 手市值下限"——茅台 1 手就是 17 万，
按金额抽会导致散户单和超大单全被顶成 1 手，四类资金的层级彻底消失（这个坑踩过）。

## 三、四类资金，方向各不相同

| 类别 | 占比 | 单笔中位数 | 手数倍率 | 行为 |
| --- | --- | --- | --- | --- |
| 小单（散户） | 82% | 8 千 | 0.35 | 追涨杀跌，最情绪化 |
| 中单 | 14% | 6.8 万 | 1.1 | 跟风 + 情绪 |
| 大单（机构） | 3.5% | 32 万 | 3.6 | 追动量、跟板块 |
| 超大单（主力） | 0.5% | 180 万 | 15 | 价值回归，越跌越买 |

净方向 `d ∈ [-1, 1]` 由这些因子经 `tanh` 压出来：

- 超大单：`gap × 46 + 板块涨幅 × 4 + 板块资金流 × 0.3 + 大盘 × 0.3 − 20 日涨幅 × 2`（便宜就买）
- 大单：`gap × 13 + 5 日涨幅 × 8 + 情绪 + 异动热度`（追）
- 小单：`5 日涨幅 × 7 + 日内涨幅 × 2.5 + 情绪 × 0.7 − gap × 5.5`（追高、跌了割）

盘口下方那四格「净流入」就是它们当日真实的成交额累加，不是画上去的。

**点火事件**：每天 3% 概率某只票在盘中某个时点被拉/砸（`st.ignite`），
一根 4%~9.5% 的脉冲，配上 `st.hot` 让游资和散户跟着冲——这是涨停板的主要来源。

## 四、板块与新闻

- 10 个板块（白酒/银行/半导体/新能源/医药/券商/军工/煤炭/AI 算力/地产），beta 0.65~1.6
- 板块资金流是 AR(1) 过程，制造"同涨同跌"的板块效应
- 48 条新闻模板，分宏观/大盘/板块/个股四个粒度，每条带三个参数：
  `drift`（改价格锚）、`liq`（改流动性系数 → 直接改盘口深度）、`sent`（改情绪）
- 粒度越小冲击越集中：个股 ×1.0、板块 ×0.65、大盘/宏观 ×0.35
- 价格锚 `st.fair` 每分钟被现价拉回 0.06%，所以消息冲击会慢慢"被遗忘"

新闻不只是弹个提示——它同时改了"估值锚"和"深度"。
利空 + 流动性 0.45 的组合意味着：价格要跌，而且盘口薄，跌起来更凶。

## 八、已知限制

- 撮合是**冲击近似**，不是逐笔撮合引擎：玩家单不排队、不占用盘口档位
- 指数按总市值加权，最大的几只票权重偏高
- 暂无排行、成就、音效
- 净值曲线按"每个交易日收盘"记一个点，日内不下钻
- 存档只记 seed + 天数，读档时引擎从第 1 天重放到当天，因此**读档会回到当天开盘**；
  224 只票跑一天约 1.4 秒，读第 5 天的档会卡 5~6 秒（后续可做增量快照）
- 跌停很少出现（个股日内很难跌到 -10%），闪崩类新闻还没做
- 截图：`shots/cdp-shot.js` 用 CDP（WebSocket + `--remote-debugging-port`）绕开了沙箱的命名管道限制，
  但必须用 pwsh + `danger-full-access` 跑；深链 `#page=stock&code=600519&demo=60&skipstart=1&rank=lhb`
  可以直接定位到某页/某股/某时刻/某个榜单页签，`skipstart=1` 跳过启动资金弹层

关键函数（engine.js）：`prnd / chOfValue / splitFill / emitFill / addPress / touchFlow`（第二区新增）、`matchAtTouch`（line 664）、`playerTick(m,st,t)`（line 684）、`submit`（line 1192）。
